✅ **GALLERY SETUP INSTRUCTIONS**

1. **Buat Tabel Database:**
   Jalankan setup file di browser:
   → http://localhost/OSIS-ALBIKO/setup-galeri.php

2. **Akses Gallery Management:**
   - Login ke dashboard
   - Buka "Edit Konten"
   - Scroll ke bawah → "Kelola Galeri Kegiatan"

3. **Cara Menggunakan:**
   ✓ Upload Foto:
     • Pilih file gambar (JPG, PNG, GIF, WebP)
     • Isi judul foto (wajib)
     • Isi deskripsi (opsional)
     • Klik "Upload Foto"

   ✓ Hapus Foto:
     • Lihat galeri yang sudah ada
     • Klik tombol "Hapus" di foto yang ingin dihapus
     • Konfirmasi penghapusan

4. **Tampilan di Homepage:**
   - Buka http://localhost/OSIS-ALBIKO/
   - Scroll ke section "Galeri Kegiatan"
   - Foto-foto akan otomatis muncul dari database

**FITUR:**
✨ Unlimited foto uploads
📝 Deskripsi untuk setiap foto
🖼️ Preview thumbnail
🗑️ Delete foto
⚡ Auto-refresh gallery setelah upload/delete
🎨 Responsive grid layout
