## 🔐 Security Implementation

### Database:
```sql
-- Database: osis_auth
CREATE TABLE users (
    id INT AUTO_INCREMENT PRIMARY KEY,
    username VARCHAR(100) UNIQUE NOT NULL,
    password VARCHAR(255) NOT NULL,
    role VARCHAR(50) DEFAULT 'user',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_username (username)
);
```

### Authentication:
```php
// Prepared statements (prevents SQL injection)
$stmt = mysqli_prepare($conn_auth, 
    "SELECT id, username, password, role FROM users WHERE username = ? LIMIT 1");
mysqli_stmt_bind_param($stmt, "s", $username);
mysqli_stmt_execute($stmt);

// Password handling (supports both hash & plain text)
if (password_verify($password, $user['password'])) {
    // Login success
} elseif ($password === $user['password']) {
    // Login success
}

// Session management
$_SESSION['login'] = true;
$_SESSION['user_id'] = $user['id'];
$_SESSION['username'] = $user['username'];
$_SESSION['role'] = $user['role'];
$_SESSION['login_time'] = time();
```

### Input Validation:
- Client-side (HTML5 required)
- Server-side (trim, empty check)
- XSS prevention (htmlspecialchars)
- CSRF prevention (if needed)

## 🐛 Troubleshooting

### "Database connection failed"
- ✅ Check MySQL is running
- ✅ Verify `connect-auth.php` credentials
- ✅ Check database `osis_auth` exists
- ✅ Run `setup-database.php` again

### "Username tidak ditemukan"
- ✅ Verify username in database
- ✅ Check case sensitivity
- ✅ Query: `SELECT * FROM users WHERE username = 'admin';`

### "Password always wrong"
- ✅ Check password matches database exactly
- ✅ Try plain text first (before hashing)
- ✅ Check phpMyAdmin for actual password value

### "Login form not showing"
- ✅ Clear browser cache (Ctrl+Shift+Delete)
- ✅ Check PHP syntax: `php -l login.php`
- ✅ Check browser console for errors (F12)

### "Session not persisting"
- ✅ Check browser cookie settings
- ✅ Verify session.save_path is writable
- ✅ Clear PHP sessions: `rm /var/lib/php/sessions/sess_*`
