🔧 Troubleshooting

❌ Database Connection Failed

  • Pastikan MySQL running: services.msc atau start mysql
  • Check credentials di connect-auth.php
  • Verify database osis_auth ada
  • Try run: setup-database.php lagi

❌ Table Users Not Found

  • Run setup-database.php di browser
  • Atau manual create table dengan SQL di documentation
  • Check phpMyAdmin: http://localhost/phpmyadmin

❌ Password Always Wrong

  • Verify password di database (exact match)
  • Check di phpMyAdmin: SELECT * FROM users
  • Try plain text password dulu sebelum implement hashing

❌ Login Form Not Showing

  • Clear browser cache: Ctrl + Shift + Delete
  • Check PHP syntax: php -l login.php
  • Check Apache error log: tail -f /var/log/apache2/error.log
  • Try open in incognito window
⚡ Quick Commands
Gunakan commands ini untuk testing cepat:

# Check PHP syntax

php -l login.php

# View database

mysql -u root -p osis_auth -e "SELECT * FROM users;"

# Clear PHP sessions

rm /var/lib/php/sessions/sess_*

# Restart Apache

sudo systemctl restart apache2

# Tail Apache error log

tail -f /var/log/apache2/error.log
